# 可比公司分析

## ⚠️ 关键：数据源优先级（首先阅读）

**始终遵循此数据源层次结构：**

1.  **首先：检查 MCP 数据源** - 如果 S&P Kensho MCP、FactSet MCP 或 Daloopa MCP 可用，则专门使用它们获取财务和交易信息
2.  **如果上述 MCP 数据源可用，请勿使用网络搜索**
3.  **仅当 MCP 不可用时：** 然后使用 Bloomberg Terminal、SEC EDGAR 文件或其他机构来源
4.  **切勿将网络搜索作为主要数据源** - 它缺乏机构级分析所需的准确性、审计追踪和可靠性

**为何重要：** MCP 源提供经过验证的、机构级的数据和适当的引用。网络搜索结果可能过时、不准确或对财务分析不可靠。

## 概述
此技能教导 Agent 构建机构级的可比公司分析，结合运营指标、估值倍数和统计基准对比。输出是一个结构化的 Excel/电子表格，通过同行比较实现明智的投资决策。

**参考材料与情境化：**

在 `examples/comps_example.xlsx` 中提供了一个可比公司分析的示例。当使用此技能目录中的此示例文件或其他示例文件时，请明智地使用它们：

**请将示例用于：**
- 理解结构层次（各部分如何衔接）
- 掌握预期的严谨程度（统计深度、文档标准）
- 学习原则（清晰的标题、透明的公式、审计追踪）

**请勿将示例用于：**
- 精确复制格式或指标
- 不考虑上下文地复制布局
- 无论受众如何都应用相同的视觉风格

**始终先问自己：**
1.  **"您有偏好的格式，还是我应该调整模板风格？"**
2.  **"受众是谁？"**（投资委员会、董事会演示、快速参考、详细备忘录）
3.  **"关键问题是什么？"**（估值、增长分析、竞争定位、效率）
4.  **"背景是什么？"**（并购评估、投资决策、行业基准对比、绩效评估）

**根据具体情况调整：**
-   **行业背景**：大型科技巨头需要与新兴 SaaS 初创公司不同的指标
-   **行业特定需求**：尽早添加相关指标（例如，科技行业的云 ARR、企业客户、开发者生态系统）
-   **公司熟悉度**：知名公司可能需要较少的背景介绍，更侧重于差异分析
-   **决策类型**：并购与持续的投资组合监控需要不同的侧重点

**核心原则：** 使用模板原则（清晰的结构、统计严谨性、透明的公式），但根据上下文调整执行方式。目标是机构质量的分析，而非机构外观的模板。

用户提供的示例和明确的偏好始终优先于默认设置。

## 核心理念
**"先构建正确的结构，然后让数据讲述故事。"**

从强制战略思考重要事项的标题开始，输入干净的数据，构建透明的公式，让统计数据自动显现。一个好的可比分析应该能让没有构建它的人立即读懂。

---

## ⚠️ 关键：公式优于硬编码 + 逐步验证

**公式，而非硬编码：**
- 每个派生值（利润率、倍数、统计量）**必须**是引用输入单元格的 Excel 公式——绝不能是预先计算好粘贴的数字
- 使用 Python/openpyxl 构建工作表时：写入 `cell.value = "=E7/C7"`（公式字符串），**而非** `cell.value = 0.687`（计算结果）
- 唯一硬编码的值应该是原始输入数据（收入、EBITDA、股价等）——并且每个这样的值都应附带一个说明其来源的单元格批注
- 原因：当输入发生变化时，模型必须自动更新。硬编码的利润率是一个等待发生的无声错误。

**与用户逐步验证：**
- 设置好结构后 → 在填充数据之前向用户展示标题布局
- 输入原始数据后 → 在构建公式之前向用户展示输入块并确认来源/期间
- 构建运营指标公式后 → 在进入估值之前向用户展示计算出的利润率并进行合理性检查
- 构建估值倍数后 → 在添加统计量之前展示倍数并确认它们看起来合理
- **不要**从头到尾构建整个工作表然后才呈现——通过确认每个部分来及早发现错误

## 第一节：文档结构与设置

### 标题区块（第1-3行）
```
第1行：[分析标题] - 可比公司分析
第2行：[公司列表及股票代码] • [公司 1 (TICK1)] • [公司 2 (TICK2)] • [公司 3 (TICK3)]
第3行：截至 [期间] | 除每股金额和比率外，所有数字单位为 [百万/十亿美元]
```

**重要性：** 立即建立上下文。任何人打开此文件都知道他们在看什么、何时创建以及如何解读数字。

### 视觉约定标准（可选 - 用户偏好和上传的模板始终优先）

**重要提示：这些仅为建议的默认值。始终优先考虑：**
1. 用户明确的格式偏好
2. 任何上传模板文件的格式
3. 公司/团队风格指南
4. 这些默认值（仅当没有其他指导时）

**建议字体与排版：**
- **字体族：** Times New Roman（专业、易读、行业标准）
- **字体大小：** 数据单元格 11pt，标题 12pt
- **粗体文本：** 章节标题、公司名称、统计指标标签

**默认颜色与底纹 — 专业蓝/灰调色板（越少越好）：**
- **保持克制** — 仅使用蓝色和灰色。请勿引入绿色、橙色、红色或多种强调色。一份干净的可比公司分析表总共使用 3-4 种颜色。
- **章节标题**（例如："经营数据与财务指标"）：
  - 深蓝色背景（`#1F4E79` 或 `#17365D` 海军蓝）
  - 白色粗体文本
  - 跨所有列整行着色
- **列标题**（例如："公司"、"收入"、"利润率"）：
  - 浅蓝色背景（`#D9E1F2` 或类似的淡蓝色）
  - 黑色粗体文本
  - 居中对齐
- **数据行：**
  - 公司数据使用白色背景
  - 公式使用黑色文本；硬编码输入使用蓝色文本
- **统计行**（最大值、第75百分位数等）：
  - 浅灰色背景（`#F2F2F2`）
  - 黑色文本，标签左对齐
- **这就是整个调色板：** 深蓝 + 浅蓝 + 浅灰 + 白。除非用户的模板另有规定，否则不要添加其他颜色。

**建议格式约定：**
- **小数精度：**
  - 百分比：1位小数（12.3%）
  - 倍数：1位小数（13.5x）
  - 美元金额：无小数，千位分隔符（69,632）
  - 利润率显示为百分比：1位小数（68.7%）
- **边框：** 无边框（干净、简约的外观）
- **对齐方式：** 所有指标居中对齐，以获得干净、统一的外观
- **单元格尺寸：** 所有列宽应统一/均匀，所有行高应一致（创建干净、专业的网格）

**注意：** 如果用户提供了模板文件或指定了不同的格式，请使用该格式。

## 第二节：经营数据与财务指标

### 核心列（从这些开始）
1.  **公司** - 名称格式一致
2.  **收入** - 规模指标（根据上下文可以是 LTM、季度或年度）
3.  **收入增长率** - 同比百分比变化
4.  **毛利润** - 收入减去销售成本
5.  **毛利率** - 毛利润/收入（基本盈利能力）
6.  **EBITDA** - 息税折旧摊销前利润
7.  **EBITDA 利润率** - EBITDA/收入（运营效率）

### 可选添加项（根据行业/目的选择）
- **季度 vs LTM** - 如果季节性重要，则两者都包括
- **自由现金流** - 适用于资本密集型或 SaaS 业务
- **自由现金流利润率** - 自由现金流/收入（现金生成效率）
- **净利润** - 适用于成熟、盈利的公司
- **营业利润** - 适用于折旧摊销差异较大的业务
- **资本支出指标** - 适用于资产密集型行业
- **40法则** - 专用于 SaaS（增长率% + 利润率%）
- **自由现金流转化率** - 用于盈利质量分析（高级）

### 公式示例（以第7行为例）
```excel
// 核心比率 - 这些总是需要计算的
毛利率 (F7): =E7/C7
EBITDA 利润率 (H7): =G7/C7

// 可选比率 - 如果相关则包括
自由现金流利润率: =[自由现金流]/[收入]
净利率: =[净利润]/[收入]
40法则: =[增长率%]+[自由现金流利润率%]
```

**黄金法则：** 每个比率都应该是 [某指标] / [收入] 或 [某指标] / [本表中的某指标]。保持简单。

### 统计区块（在公司数据之后）

**关键：为所有可比指标（比率、利润率、增长率、倍数）添加统计公式。**

```
[留一个空行用于视觉分隔]
- 最大值: =MAX(B7:B9)
- 第75百分位数: =QUARTILE(B7:B9,3)
- 中位数: =MEDIAN(B7:B9)
- 第25百分位数: =QUARTILE(B7:B9,1)
- 最小值: =MIN(B7:B9)
```

**需要统计的列（可比指标）：**
- 收入增长率%、毛利率%、EBITDA 利润率%、每股收益
- 企业价值/收入、企业价值/EBITDA、市盈率、股息收益率%、贝塔系数

**不需要统计的列（规模指标）：**
- 收入、EBITDA、净利润（绝对规模因公司规模而异）
- 市值、企业价值（在不同规模的公司之间不可比）

**注意：** 在公司数据和统计行之间添加一个空行用于视觉分隔。请**不要**添加"行业统计"或"估值统计"标题行。

**为什么百分位数很重要：** 它们显示分布，而不仅仅是平均值。第75百分位数的倍数告诉你"优质"公司的交易水平。

## 第三节：估值倍数与投资指标

### 核心估值列（从这些开始）
1.  **公司** - 与经营数据部分顺序相同
2.  **市值** - 当前市场估值
3.  **企业价值** - 市值 ± 净债务/现金
4.  **企业价值/收入** - 市场为每美元销售额支付多少
5.  **企业价值/EBITDA** - 市场为每美元利润支付多少
6.  **市盈率** - 价格相对于净利润的比率

### 可选估值指标（根据上下文选择）
- **自由现金流收益率** - 自由现金流/市值（用于现金流分析）
- **市盈增长比率** - 市盈率/增长率（用于成长型公司）
- **市净率** - 市场价值与账面价值之比（用于资产密集型业务）
- **净资产收益率/总资产收益率** - 回报指标（用于盈利能力比较）
- **收入/EBITDA 复合年增长率** - 历史增长率（用于趋势分析）
- **资产周转率** - 收入/资产（用于运营效率分析）
- **债务/权益** - 杠杆率（用于资本结构分析）
**核心原则：** 包含 3-5 个对您所在行业至关重要的核心倍数。不要仅仅因为可以就包含所有可能的指标。

### 公式示例
```excel
// 核心倍数 - 始终包含这些
EV/收入：=[企业价值]/[最近十二个月收入]
EV/EBITDA：=[企业价值]/[最近十二个月 EBITDA]
市盈率：=[市值]/[净利润]

// 可选倍数 - 如果数据可用则包含
自由现金流收益率：=[最近十二个月自由现金流]/[市值]
市盈增长比率：=[市盈率]/[增长率 %]
```

### 交叉引用规则
**关键：** 估值倍数**必须**引用运营指标部分。切勿重复输入相同的原始数据。如果收入在 C7 单元格，那么 EV/收入公式应引用 C7。

### 统计区块
结构与运营部分相同：每个指标都包含最大值、75分位数、中位数、25分位数、最小值。在公司数据和统计之间添加一个空行以进行视觉分隔。**不要**添加"估值统计"标题行。

## 第 4 部分：注释与方法论文档

### 必需组件

**数据来源与质量：**
- 数据来自何处？（S&P Kensho MCP、FactSet MCP、Daloopa MCP、Bloomberg、SEC 文件）
- 涵盖哪个时期？（2024 年第四季度，经审计数据）
- 如何验证？（与 10-K/10-Q 交叉核对）
- 注意：如果可用，优先使用 MCP 数据源（S&P Kensho、FactSet、Daloopa），以获得更好的准确性和可追溯性

**关键定义：**
- EBITDA 计算方法（毛利润 + D&A，或营业利润 + D&A）
- 自由现金流公式（经营现金流 - 资本支出）
- 特殊指标说明（40法则、自由现金流转化率）
- 时间段定义（最近十二个月、复合年增长率计算周期）

**估值方法论：**
- 企业价值如何计算？（市值 + 净债务）
- 使用了哪些增长率？（历史复合年增长率、远期预测）
- 是否进行了任何调整？（排除一次性项目、标准化利润率）

**分析框架：**
- 投资论点是什么？（云/SaaS 效率）
- 哪些指标最重要？（现金生成、资本效率）
- 读者应如何解读统计数据？（分位数提供背景信息）

## 第 5 部分：选择正确的指标（决策框架）

### 从"我要回答什么问题？"开始

**"哪家公司被低估了？"**
→ 关注：EV/收入、EV/EBITDA、市盈率、市值
→ 忽略：运营细节、增长指标

**"哪家公司效率最高？"**
→ 关注：毛利率、EBITDA 利润率、自由现金流利润率、资产周转率
→ 忽略：规模指标、绝对美元金额

**"哪家公司增长最快？"**
→ 关注：收入增长率%、EBITDA 复合年增长率、用户/客户增长率
→ 忽略：利润率指标、杠杆比率

**"哪家是最好的现金生成器？"**
→ 关注：自由现金流、自由现金流利润率、自由现金流转化率、资本支出强度
→ 忽略：EBITDA、市盈率

### 行业特定指标选择

**软件/SaaS：**
必须有：收入增长率、毛利率、40法则
可选：年度经常性收入、净美元留存率、客户获取成本回收期
忽略：资产周转率、库存指标

**制造业/工业：**
必须有：EBITDA 利润率、资产周转率、资本支出/收入
可选：资产回报率、库存周转率、积压订单
忽略：40法则、SaaS 指标

**金融服务：**
必须有：股本回报率、资产回报率、效率比率、市盈率
可选：净息差、贷款损失准备金
忽略：毛利率、EBITDA（对银行无意义）

**零售/电子商务：**
必须有：收入增长率、毛利率、库存周转率
可选：同店销售额、客户获取成本
忽略：高研发或资本支出指标

### "5-10 法则"

**5 个运营指标** - 收入、增长率、2-3 个利润率/效率指标
**5 个估值指标** - 市值、企业价值、3 个倍数
**= 总计 10 列** - 足以讲述故事，又不会因过多而失去主线

如果指标超过 15 个，可能包含了噪音。请严格编辑。

## 第 6 部分：最佳实践与质量检查

### 开始之前
1.  **定义同行组** - 公司必须真正可比（相似的商业模式、规模、地域）
2.  **选择正确的时期** - 最近十二个月平滑季节性；季度数据显示趋势
3.  **预先标准化单位** - 百万与十亿的决定会影响一切
4.  **映射数据源** - 了解每个数字的来源

### 构建过程中
1.  **首先输入所有原始数据** - 在编写公式之前完成蓝色文本
2.  **为所有硬编码输入添加单元格注释** - 右键单击单元格 → 插入批注 → 记录来源或假设

   **对于有来源的数据，准确注明出处：**
   - 示例："Bloomberg Terminal - MSFT Equity DES，访问日期 2024-10-02"
   - 示例："2024 年第四季度 10-K 文件，第 42 页，'总收入'项目"
   - 示例："截至 2024-10-02 的 FactSet 共识预期"
   - **尽可能包含超链接**：右键单击单元格 → 链接 → 粘贴 SEC 文件、数据源或报告的 URL

   **对于假设，解释推理过程：**
   - 示例："假设 EBITDA 利润率为 15%，基于同行中位数，公司未披露"
   - 示例："估计企业价值为市值 + 5000 万美元净债务（来自第三季度资产负债表，第四季度尚未公布）"
   - 示例："远期市盈率基于华尔街共识每股收益 3.45 美元（12 位分析师估计的平均值）"

   **为什么这很重要**：支持审计跟踪、数据验证、假设透明度和未来更新
3.  **逐行构建公式** - 在继续之前测试每个计算
4.  **对标题使用绝对引用** - $C$6 锁定标题行
5.  **格式一致** - 百分比显示为百分比，而非小数
6.  **添加条件格式** - 自动突出显示异常值

### 合理性检查
- **利润率测试**：毛利率 > EBITDA 利润率 > 净利润率（根据定义始终成立）
- **倍数合理性**：
  - EV/收入：通常为 0.5-20 倍（因行业差异很大）
  - EV/EBITDA：通常为 8-25 倍（跨行业相对一致）
  - 市盈率：通常为 10-50 倍（取决于增长率）
- **增长-倍数相关性**：更高的增长通常意味着更高的倍数
- **规模-效率权衡**：更大的公司通常拥有更好的利润率（规模效益）
### 常见错误避免
❌ 在公式中混淆市值与企业价值
❌ 分子和分母使用不同时间周期（LTM 与季度数据）
❌ 在公式中硬编码数字而非使用单元格引用
❌ **硬编码输入项未在单元格批注中注明数据来源或解释假设**
❌ 缺少指向 SEC 文件或数据源（如可用）的超链接
❌ 包含过多指标但目的不明确
❌ 包含不可比公司（商业模式不同）
❌ 使用过时数据且未披露
❌ 错误计算百分比的平均值（应使用中位数）

## 第 7 部分：工作流程与实用技巧

### 分步流程
1.  **搭建结构**（30 分钟）
    - 创建所有表头
    - 设置单元格格式（输入项用蓝色，公式用黑色）
    - 锁定单位和日期引用

2.  **收集数据**（60-90 分钟）
    - 从主要来源提取数据（如有可用，使用 S&P Kensho MCP、FactSet MCP、Daloopa MCP；否则使用彭博、SEC）
    - 将所有原始数字以蓝色输入
    - 在注释部分记录数据来源

3.  **构建公式**（30 分钟）
    - 从简单比率开始（利润率）
    - 逐步构建倍数（企业价值/收入）
    - 添加交叉检查（利润率是否合理？）

4.  **添加统计量**（15 分钟）
    - 为所有列复制公式结构
    - 验证范围是否正确（例如 B7:B9，而非 B7:B10）
    - 检查四分位数逻辑

5.  **质量控制**（30 分钟）
    - 运行合理性检查
    - 验证公式引用
    - 检查是否存在 #DIV/0! 或 #REF! 错误
    - 与已知基准进行比较

6.  **文档记录**（15 分钟）
    - 完成注释部分
    - 添加数据来源
    - 定义方法论
    - 为分析添加日期戳

### 专业技巧
- **保存模板**：一次构建，永久复用
- **对异常值进行颜色编码**：对大于 2 个标准差的值使用条件格式
- **链接到源文件**：添加指向彭博截图或 SEC 文件的超链接
- **版本控制**：保存为 "Comps_v1_2024-12-15" 等带有清晰日期的文件名
- **协作审查**：请他人检查你的公式

## 第 10 节：危险信号与警示信号

### 数据质量问题
🚩 时间周期不一致（混合季度和年度数据）
🚩 数据缺失且无解释
🚩 不同数据源之间存在显著差异（>10% 的方差）

### 估值危险信号
🚩 负 EBITDA 的公司使用 EBITDA 倍数进行估值（应改用收入倍数）
🚩 市盈率 >100 倍但没有高速增长故事支撑
🚩 利润率不符合行业常理

### 可比性问题
🚩 不同的财年截止日期（导致时间问题）
🚩 混合纯业务公司和综合企业集团
🚩 业务模式存在实质性差异却被标记为"可比公司"

**如有疑问，排除该公司。** 拥有 3 个完美的可比公司胜过 6 个有问题的可比公司。

## 第 11 节：公式参考指南

### 基本 Excel 公式
```excel
// 统计函数
=AVERAGE(range)          // 简单平均值
=MEDIAN(range)           // 中位数
=QUARTILE(range, 1)      // 第 25 百分位数
=QUARTILE(range, 3)      // 第 75 百分位数
=MAX(range)              // 最大值
=MIN(range)              // 最小值
=STDEV.P(range)          // 标准差

// 财务计算
=B7/C7                   // 简单比率（利润率）
=SUM(B7:B9)/3            // 多个公司的平均值
=IF(B7>0, C7/B7, "N/A")  // 条件计算
=IFERROR(C7/D7, 0)       // 处理除零错误

// 跨工作表引用
='Sheet1'!B7             // 引用另一个工作表
=VLOOKUP(A7, Table1, 2)  // 从数据表中查找
=INDEX(MATCH())          // 高级查找

// 格式化
=TEXT(B7, "0.0%")        // 格式化为百分比
=TEXT(C7, "#,##0")       // 千位分隔符
```

### 常用比率公式
```excel
毛利率 = 毛利润 / 收入
EBITDA 利润率 = EBITDA / 收入
自由现金流利润率 = 自由现金流 / 收入
自由现金流转化率 = 自由现金流 / 经营现金流
净资产收益率 = 净利润 / 股东权益
总资产收益率 = 净利润 / 总资产
资产周转率 = 收入 / 总资产
负债权益比 = 总负债 / 股东权益
```

## 关键原则总结

1.  **结构驱动洞察** - 正确的标题强制正确的思考
2.  **少即是多** - 5-10 个关键指标胜过 20 个无关指标
3.  **根据问题选择指标** - 估值分析 ≠ 效率分析
4.  **统计揭示模式** - 中位数/百分位数比平均值揭示更多信息
5.  **透明度胜过复杂性** - 使用每个人都能理解的简单公式
6.  **可比性是王道** - 排除可比性差的公司胜过强行纳入
7.  **记录您的选择** - 在注释部分解释选择了哪些指标以及原因

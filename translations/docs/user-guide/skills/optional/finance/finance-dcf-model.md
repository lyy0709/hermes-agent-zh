# DCF 模型构建器

## 概述

此技能遵循投行标准，为股权估值创建机构级质量的 DCF 模型。每次分析都会生成一个详细的 Excel 模型（敏感性分析包含在 DCF 工作表的底部）。

## 工具

- 默认使用用户提供的所有信息以及可用于数据源的 MCP 服务器。

## 关键约束 - 首先阅读这些

这些约束适用于所有 DCF 模型构建过程。开始前请仔细阅读：

**公式优先于硬编码（不可协商）：**
- 每个预测、利润率、折现因子、现值和敏感性单元格都必须是实时 Excel 公式 —— 绝不是在 Python 中计算并作为数字写入的值
- 使用 openpyxl 时：`ws["D20"] = "=D19*(1+$B$8)"` 是正确的；`ws["D20"] = calculated_revenue` 是错误的
- 唯一允许的硬编码数字是：(1) 原始历史输入，(2) 假设驱动因素（增长率、WACC 输入、终值增长率 g），(3) 当前市场数据（股价、债务余额）
- 如果你发现自己在 Python 中计算某些内容并写入结果 —— 请停止。当用户更改假设时，模型必须能够灵活调整。

**与用户逐步验证（不要端到端构建）：**
- 数据检索后 → 向用户展示原始输入块（收入、利润率、股份数、净债务）并在预测前确认
- 收入预测后 → 展示预测的顶线收入和增长率，在构建利润率之前确认
- 自由现金流构建后 → 展示完整的自由现金流计划表，在计算 WACC 前确认逻辑
- WACC 计算后 → 展示计算过程和输入，在折现前确认
- 终值 + 现值计算后 → 展示股权桥接（企业价值 → 股权价值 → 每股价值），在创建敏感性表格前确认
- 在每个阶段捕获错误 —— 在敏感性表格构建后发现错误的利润率假设意味着需要重建所有下游内容

**敏感性表格：**
- **使用奇数的行和列**（标准：5×5，有时 7×7）—— 这保证了存在一个真正的中心单元格
- **中心单元格 = 基准情况。** 构建轴值，使中间行标题和中间列标题恰好等于模型的实际假设（例如，如果基准 WACC = 9.0%，则中间行为 9.0%；如果终值增长率 g = 3.0%，则中间列为 3.0%）。因此，中心单元格的输出必须等于模型实际隐含的股价 —— 这是验证表格构建正确的健全性检查。
- **突出显示中心单元格**，使用中蓝色填充 (`#BDD7EE`) + 粗体字体，以便立即看出哪个单元格是基准情况。
- 使用完整的 DCF 重新计算公式填充所有单元格（通常是 3 个表格 × 25 个单元格 = 75 个）
- 使用 openpyxl 循环以编程方式写入公式
- 不允许占位符文本、不允许线性近似、不需要手动步骤
- 每个单元格必须针对该假设组合重新计算完整的 DCF

**单元格注释：**
- 在创建每个硬编码值时立即添加单元格注释
- 格式："来源：[系统/文档]，[日期]，[参考]，[URL（如果适用）]"
- 在进入下一部分之前，每个蓝色输入都必须有注释
- 不要推迟到最后或写 "TODO: 添加来源"

**模型布局规划：**
- 在写入任何公式之前，定义所有部分的行位置
- 首先写入所有标题和标签
- 其次写入所有部分分隔符和空行
- 然后使用锁定的行位置写入公式
- 创建后立即测试公式

**公式重新计算：**
- 交付前运行 `python recalc.py model.xlsx 30`
- 修复所有错误，直到状态为 "success"
- 要求零公式错误（#REF!、#DIV/0!、#VALUE! 等）

**情景块：**
- 为熊市/基准/牛市情况创建单独的块
- 在每个块内，水平显示跨预测年份的假设
- 使用 IF 公式：`=IF($B$6=1,[熊市单元格],IF($B$6=2,[基准单元格],[牛市单元格]))`
- 验证公式引用了正确的情景块单元格

## DCF 流程工作流

### 步骤 1：数据检索和验证

从 MCP 服务器、用户提供的数据和网络获取数据。

**数据源优先级：**
1.  **MCP 服务器**（如果已配置）- 来自 Daloopa 等提供商的结构化财务数据
2.  **用户提供的数据** - 来自其研究的历史财务数据
3.  **网络搜索/获取** - 当前价格、贝塔系数、债务和现金（需要时）
**验证清单：**
- 验证净债务与净现金（对估值至关重要）
- 确认稀释后流通股数（检查近期股票回购/发行情况）
- 验证历史利润率与商业模式一致
- 将收入增长率与行业基准进行交叉核对
- 验证税率是否合理（通常在 21-28% 之间）

### 步骤 2：历史分析（3-5 年）

分析并记录：
- **收入增长趋势**：计算复合年增长率，识别驱动因素
- **利润率变化**：跟踪毛利率、息税前利润率、自由现金流利润率
- **资本密集度**：折旧摊销和资本支出占收入的百分比
- **营运资本效率**：净营运资本变动占收入增长的百分比
- **回报指标**：投入资本回报率、净资产收益率趋势

创建汇总表，显示：
```
历史指标（最近十二个月）：
收入：X 百万美元
收入增长：X% 复合年增长率
毛利率：X%
息税前利润率：X%
折旧摊销占收入百分比：X%
资本支出占收入百分比：X%
自由现金流利润率：X%
```

### 步骤 3：构建收入预测

**方法论：**
1.  从最新的实际收入（最近十二个月或最近财年）开始
2.  为每个预测年份应用增长率
3.  同时显示美元金额和计算出的增长百分比

**增长率框架：**
- 第 1-2 年：较高增长，反映近期可见性
- 第 3-4 年：逐渐放缓，趋向行业平均水平
- 第 5 年及以上：接近永续增长率

**公式结构：**
- 收入（第 N 年）= 收入（第 N-1 年）× (1 + 增长率)
- 增长百分比（第 N 年）= 收入（第 N 年）/ 收入（第 N-1 年）- 1

**三情景方法：**
```
悲观情景：保守增长（例如，8-12%）
基准情景：最可能情景（例如，12-16%）
乐观情景：乐观增长（例如，16-20%）
```

### 步骤 4：运营费用建模

**固定/可变成本分析：**

运营费用应模拟现实的经营杠杆：
- **销售与营销费用**：通常占收入的 15-40%，取决于商业模式
- **研发费用**：对于科技公司，通常占收入的 10-30%
- **一般及行政费用**：通常占收入的 8-15%，随着公司规模扩大显示出杠杆效应

**关键原则：**
- 所有百分比均基于**收入**，而非毛利
- 模拟经营杠杆：百分比应随着收入规模扩大而下降
- 为销售与营销、研发、一般及行政费用保持独立的明细项目
- 计算息税前利润 = 毛利 - 总运营费用

**利润率扩张框架：**
```
当前状态 → 目标状态（第 5 年）
毛利率：X% → Y%（基于规模、效率进行论证）
息税前利润率：X% → Y%（收入增长 + 运营费用杠杆的结果）
```

### 步骤 5：自由现金流计算

**按正确顺序构建自由现金流：**

```
息税前利润
(-) 税费（息税前利润 × 税率）
= 税后净营业利润
(+) 折旧摊销（非现金费用，占收入的百分比）
(-) 资本支出（占收入的百分比，通常为 4-8%）
(-) Δ 净营运资本（营运资本变动）
= 无杠杆自由现金流
```

**营运资本建模：**
- 计算为收入变动（增量收入）的百分比
- 典型范围：收入变动的 -2% 到 +2%
- 负数 = 现金来源（营运资本释放）
- 正数 = 现金使用（营运资本增加）

**维持性资本支出与增长性资本支出：**
- 维持性资本支出：维持当前运营（约收入的 2-3%）
- 增长性资本支出：支持扩张（额外的收入的 2-5%）
- 总资本支出应与公司的增长战略保持一致

### 步骤 6：资本成本研究

**用于股权成本的资本资产定价模型方法论：**

```
股权成本 = 无风险利率 + Beta × 股权风险溢价

其中：
- 无风险利率 = 当前 10 年期国债收益率
- Beta = 股票相对于市场指数的 5 年月度 Beta 值
- 股权风险溢价 = 5.0-6.0%（市场标准）
```

**债务成本计算：**

```
税后债务成本 = 税前债务成本 × (1 - 税率)

从以下方面确定税前债务成本：
- 信用评级（如有）
- 公司债券的当前收益率
- 财务报表中的利息支出 / 总债务
```

**资本结构权重：**

```
股权市场价值 = 当前股价 × 流通股数
净债务 = 总债务 - 现金及等价物
企业价值 = 市值 + 净债务

股权权重 = 市值 / 企业价值
债务权重 = 净债务 / 企业价值

加权平均资本成本 = (股权成本 × 股权权重) + (税后债务成本 × 债务权重)
```

**特殊情况：**
- **净现金状况**：如果现金 > 债务，则净债务为**负数**
  - 债务权重可能为负
  - 加权平均资本成本计算相应调整
- **无债务**：加权平均资本成本 = 股权成本

**典型的加权平均资本成本范围：**
- 大盘股，稳定：7-9%
- 成长型公司：9-12%
- 高增长/高风险：12-15%

### 步骤 7：折现率应用（5-10 年预测）

**年中惯例：**
- 假设现金流发生在年中
- 折现期：0.5, 1.5, 2.5, 3.5, 4.5 等
- 折现因子 = 1 / (1 + 加权平均资本成本)^期数

**现值计算：**
```
对于每个预测年份：
自由现金流现值 = 无杠杆自由现金流 × 折现因子

示例（第 1 年）：
自由现金流 = 1,000 美元
加权平均资本成本 = 10%
期数 = 0.5
折现因子 = 1 / (1.10)^0.5 = 0.9535
现值 = 1,000 美元 × 0.9535 = 954 美元
```

**预测期选择：**
- **5 年**：大多数分析的标准
- **7-10 年**：具有较长增长跑道的高增长公司
- **3 年**：成熟、稳定的企业

### 步骤 8：终值计算

**永续增长法（首选）：**

```
终值自由现金流 = 最后一年自由现金流 × (1 + 永续增长率)
终值 = 终值自由现金流 / (加权平均资本成本 - 永续增长率)

关键约束：永续增长率 < 加权平均资本成本（否则价值无限大）
```

**永续增长率选择：**
- 保守：2.0-2.5%（GDP 增长率）
- 适中：2.5-3.5%
- 激进：3.5-5.0%（仅适用于市场领导者）

**不得超过**：无风险利率或长期 GDP 增长率

**退出倍数法（替代方法）：**
```
终值 = 最后一年息税折旧摊销前利润 × 退出倍数

其中退出倍数来自：
- 行业可比交易倍数
- 过往交易倍数
- 典型范围：8-15 倍息税折旧摊销前利润
```

**终值现值：**
```
终值现值 = 终值 / (1 + 加权平均资本成本)^最终期数

其中最终期数考虑时间因素：
采用年中惯例的 5 年模型：期数 = 4.5
```

**终值合理性检查：**
- 应占企业价值的 50-70%
- 如果 >75%，模型可能过度依赖终值假设
- 如果 <40%，检查终值假设是否过于保守
### 步骤 9：企业价值到股权价值的转换

**估值摘要结构：**

```
(+) 预测自由现金流现值总和 = X 百万美元
(+) 终值现值 = Y 百万美元
= 企业价值 = Z 百万美元

(-) 净债务 [或 + 净现金，如果为负] = A 百万美元
= 股权价值 = B 百万美元

÷ 稀释后流通股数 = C 百万股
= 隐含每股价格 = XX.XX 美元

当前股价 = YY.YY 美元
隐含回报率 = (隐含价格 / 当前价格) - 1 = XX%
```

**关键调整项：**
- **净债务 = 总债务 - 现金及等价物**
  - 如果为正：从企业价值中减去（降低股权价值）
  - 如果为负（净现金）：加到企业价值上（增加股权价值）
- **使用稀释后股数**：包括期权、限制性股票单位、可转换证券
- **其他调整项**（如适用）：
  - 少数股东权益
  - 养老金负债
  - 经营租赁义务

**估值输出格式：**
```csv
估值组成部分,金额（百万美元）
预测期自由现金流现值,X.X
终值现值,Y.Y
企业价值,Z.Z
(-) 净债务,A.A
股权价值,B.B
,,
流通股数（百万）,C.C
隐含每股价格,$XX.XX
当前股价,$YY.YY
隐含上涨/下跌空间,+XX%
```

### 步骤 10：敏感性分析

在 DCF 工作表的底部构建**三个敏感性表格**，展示估值如何随不同假设变化：

1.  **WACC 与终值增长率** - 展示企业价值对折现率和永续增长率的敏感性
2.  **收入增长率与息税前利润率** - 展示收入增长和经营杠杆的影响
3.  **贝塔系数与无风险利率** - 展示对股权成本组成部分的敏感性

**实现方法**：这些是简单的二维网格（**不是** Excel 的"数据表"功能），每个单元格中包含公式。每个单元格必须包含针对该特定假设组合的完整 DCF 重新计算。关于使用 openpyxl 以编程方式填充所有 75 个单元格的详细要求，请参见"关键约束"部分。

### 情景区块选择模式 - 遵循此方法

**假设按情景组织在独立的区块中：**

**关键结构 - 每个章节标题占三行：**

```csv
悲观情景假设 (章节标题，跨列合并单元格)
假设,FY1,FY2,FY3,FY4,FY5
收入增长率 (%),12%,10%,9%,8%,7%
息税前利润率 (%),45%,44%,43%,42%,41%

基准情景假设 (章节标题，跨列合并单元格)
假设,FY1,FY2,FY3,FY4,FY5
收入增长率 (%),16%,14%,12%,10%,9%
息税前利润率 (%),48%,49%,50%,51%,52%

乐观情景假设 (章节标题，跨列合并单元格)
假设,FY1,FY2,FY3,FY4,FY5
收入增长率 (%),20%,18%,15%,13%,11%
息税前利润率 (%),50%,51%,52%,53%,54%
```

**每个情景区块必须有一个列标题行**，紧接在章节标题下方，显示预测年份（FY2025E、FY2026E 等）。没有这个，用户就无法判断哪个假设值对应哪个年份。

**如何引用假设 - 创建一个汇总列：**
1.  情景选择器单元格（例如 B6）包含 1=悲观、2=基准 或 3=乐观
2.  创建一个汇总列，使用 INDEX 或 OFFSET 公式从正确的情景区块中提取数据
3.  预测公式引用汇总列（清晰的单元格引用）
4.  每个情景区块包含预测年份的完整 DCF 假设集

**推荐的汇总列模式（使用 INDEX）：**
`=INDEX(B10:D10, 1, $B$6)`

**不要这样做 - 在整个模型中散布 IF 语句：**
`=IF($B$6=1,[悲观区块单元格],IF($B$6=2,[基准区块单元格],[乐观区块单元格]))`

汇总列方法集中了逻辑，使模型更易于审计。

### 正确的收入预测模式

**使用 INDEX 公式创建汇总列，然后在预测中引用它：**

**步骤 1 - 为 FY1 增长率创建汇总列：**
`=INDEX([悲观 FY1 增长率]:[乐观 FY1 增长率], 1, $B$6)`

**步骤 2 - 收入预测引用汇总列：**
`第 1 年收入：=D29*(1+$E$10)`

其中：
- D29 = 上一年收入
- $E$10 = FY1 增长率的汇总列单元格（包含 INDEX 公式）
- $B$6 = 情景选择器（1=悲观，2=基准，3=乐观）

**这种方法比在每个预测公式中嵌入 IF 语句更清晰**，并且使得审计正在使用哪个情景假设变得容易得多。

### 正确的自由现金流公式模式

**使用带有 INDEX 公式的汇总列，然后在自由现金流计算中引用它们：**

**汇总列方法：**
```csv
项目,公式,引用
折旧与摊销,=E29*$E$21,$E$21 = 折旧与摊销百分比的汇总列
资本支出,=E29*$E$22,$E$22 = 资本支出百分比的汇总列
营运资本变动,=(E29-D29)*$E$23,$E$23 = 营运资本百分比的汇总列
无杠杆自由现金流,=E57+E58-E60-E62,E57=税后净营业利润 E58=折旧与摊销 E60=资本支出 E62=营运资本变动
```

**每个汇总列单元格包含一个 INDEX 公式**，该公式根据情景选择器从适当的情景区块中提取数据。这使得预测公式保持清晰且易于审计。

在编写公式之前，请确认情景区块的行位置并设置好汇总列。

### 正确的单元格批注格式

**每个硬编码值都需要以下格式：**

"来源：[系统/文档]，[日期]，[参考]，[URL，如适用]"

**示例：**
```csv
项目,来源批注
股价,来源：市场数据脚本 2025-10-12 收盘价
流通股数,来源：10-K FY2024 第 45 页 附注 12
历史收入,来源：10-K FY2024 第 32 页 合并报表
贝塔系数,来源：市场数据脚本 2025-10-12 5 年月度贝塔
共识预期,来源：管理层指引 2024 年第三季度财报电话会议
```

### 正确的假设表结构

**关键：每个情景区块需要三个结构元素：**

1.  **章节标题行**（合并单元格）：例如，"悲观情景假设"
2.  **列标题行**显示年份 - **这是必需的，不要跳过**
3.  包含假设值的**数据行**

**结构：**
```csv
悲观情景假设 (章节标题 - 跨列 A:G 合并)
假设,FY1,FY2,FY3,FY4,FY5
收入增长率 (%),X%,X%,X%,X%,X%
息税前利润率 (%),X%,X%,X%,X%,X%
终值增长率,X%,,,,
加权平均资本成本,X%,,,,

基准情景假设 (章节标题 - 跨列 A:G 合并)
假设,FY1,FY2,FY3,FY4,FY5
收入增长率 (%),X%,X%,X%,X%,X%
息税前利润率 (%),X%,X%,X%,X%,X%
终值增长率,X%,,,,
加权平均资本成本,X%,,,,

乐观情景假设 (章节标题 - 跨列 A:G 合并)
假设,FY1,FY2,FY3,FY4,FY5
收入增长率 (%),X%,X%,X%,X%,X%
息税前利润率 (%),X%,X%,X%,X%,X%
终值增长率,X%,,,,
加权平均资本成本,X%,,,,
```
**如果没有显示预测年份（FY2025E、FY2026E 等）的列标题行，用户就无法知道哪个假设值对应哪个年份。这一行是必需的。**

**然后创建一个合并列**（通常是选定场景区块右侧的下一列），该列使用 INDEX 公式根据案例选择器从选定的场景区块中提取数据。这个合并列就是你的预测公式所引用的。

### 正确的行规划流程

**1. 首先写入所有标题和标签：**
```csv
行,内容

2,股票代码 | 日期 | 年末
4,案例选择器
7,关键假设
26,假设标题
27-31,增长假设

```

**2. 写入所有分区线和空行**

**3. 然后使用锁定的行位置编写公式**

**4. 创建后立即测试公式**

**可以将其想象成建筑施工：**
- 正确做法：先浇筑地基，再砌墙（结构稳定）
- 错误做法：先砌墙，再浇筑地基（墙会倒塌）

**Excel 版本：**
- 正确做法：先添加标题，再编写公式（公式稳定）
- 错误做法：先编写公式，再添加标题（公式会出错）

### 正确的敏感性表格实现

**重要提示**：这些**不是** Excel 的"数据表"功能。这些是简单的网格，你使用 openpyxl 在其中编写常规公式。是的，这意味着总共大约 75 个公式（3 个表格 × 每个 25 个单元格），但这很直接且是必需的。

**使用公式进行程序化填充：**

每个敏感性表格必须完全填充公式，这些公式为每个假设组合重新计算隐含股价。**不要使用 Excel 的数据表功能**（它需要手动操作，无法通过 openpyxl 自动化）。

**实现方法 - 具体示例：**

**表格结构 — 5×5 网格（奇数维度，基准情况居中）：**

如果模型的基准 WACC = 9.0%，基准永续增长率 = 3.0%，则围绕这些值对称构建坐标轴：

```csv
WACC vs 永续增长率,  2.0%,  2.5%,  3.0%,  3.5%,  4.0%
              8.0%,       [公式], [公式], [公式], [公式], [公式]
              8.5%,       [公式], [公式], [公式], [公式], [公式]
              9.0%,       [公式], [公式], [★  ], [公式], [公式]   ← 中间行 = 基准 WACC
              9.5%,       [公式], [公式], [公式], [公式], [公式]
             10.0%,       [公式], [公式], [公式], [公式], [公式]
                                   ↑
                          中间列 = 基准永续增长率 g
```

**★ = 中心单元格。** 其公式输出**必须**等于模型的实际隐含股价（来自估值摘要）。对此单元格应用中蓝色填充（`#BDD7EE`）和粗体字体，以便基准情况在视觉上得到锚定。

**坐标轴值规则：** `axis_values = [基准值 - 2*步长, 基准值 - 步长, 基准值, 基准值 + 步长, 基准值 + 2*步长]` — 围绕基准值对称，奇数数量保证有中心。

**公式模式 - 单元格 B88（WACC=8.0%，永续增长率=2.0%）：**

B88 中的公式应使用以下值重新计算隐含价格：
- 来自行标题的 WACC：`$A88` (8.0%)
- 来自列标题的永续增长率：`B$87` (2.0%)

**推荐方法：** 引用主要的 DCF 计算，但替换这些值。

**示例公式结构：**
`=([使用 $A88 作为折现率的 PV FCFs 总和] + [使用 B$87 作为增长率、$A88 作为 WACC 的终值] - [净债务]) / [股份数]`

**关键 - 为 5x5 网格中的每个单元格编写一个公式（每个表格 25 个单元格，总共 75 个单元格）。** 使用 openpyxl 在循环中以编程方式写入这些公式。**不要**跳过此步骤或留下占位符文本。

**Python 实现模式：**
```python
# 用于填充敏感性表格的伪代码
for row_idx, wacc_value in enumerate(wacc_range):
    for col_idx, term_growth_value in enumerate(term_growth_range):
        # 构建使用 wacc_value 和 term_growth_value 的公式
        formula = f"=<使用 {wacc_value} 和 {term_growth_value} 重新计算 DCF>"
        ws.cell(row=start_row+row_idx, column=start_col+col_idx).value = formula
```

**敏感性表格必须在模型打开时立即生效，无需用户执行任何手动步骤。**

&lt;common_mistakes>

本节包含构建 DCF 模型时应避免的所有**错误**模式。

### 错误：简化的敏感性表格近似或占位符文本

**不要使用线性近似：**
```
// 错误 - 线性近似
B97: =B88*(1+(0.096-0.116))    // 假设线性关系

// 错误 - 除法捷径
B105: =B88/(1+(E48-0.07))      // 没有重新计算完整的 DCF
```

**不要留下占位符文本：**
```
// 错误 - 占位符注释
"注意：使用 Excel 数据表功能（数据 → 假设分析 → 数据表）填充敏感性表格。"

// 错误 - 空单元格
[因为"这很复杂"而将单元格留空]
```

**不要混淆术语：**
- ❌ "敏感性表格需要 Excel 的数据表功能"（不 - 那是我们无法使用的特定 Excel 工具）
- ✅ "敏感性表格是每个单元格都有公式的简单网格"（对 - 这就是我们要构建的）

**为什么这些捷径是错误的：**
- 线性近似公式实际上并没有重新计算 DCF - 它们只是应用简单的数学调整
- 关系不是线性的，因此结果将不准确
- 占位符文本需要用户手动干预
- 模型在交付时不能立即使用
- 不专业或不符合交付给客户的要求
- 空单元格 = 不完整的交付物

**需要拒绝的常见合理化理由：**
"编写 75 多个公式感觉很复杂，所以我给用户留个便条，让他们手动完成。"

**现实情况：** 当你在 Python 中使用 openpyxl 进行循环时，编写 75 个公式是很直接的。每个公式都遵循相同的模式 - 只需替换行/列值。这是交付物的必要组成部分。

**正确做法：** 用公式填充每个敏感性单元格，这些公式为特定的假设组合重新计算完整的 DCF。

### 错误：缺少单元格注释

**不要这样做：**
- 创建所有硬编码输入但没有注释
- 认为"我稍后再添加"
- 写上"待办事项：添加来源"
- 留下没有文档记录的蓝色输入
**错误原因：**
- 无法验证数据来源
- 不符合 xlsx 技能要求
- 未做好审计准备
- 浪费时间在后期修复

**正确做法：** 在创建**每个**硬编码值时，立即添加单元格批注

### 错误：公式行引用错误

**现象：**
FCF 部分引用了错误的假设行：
`D&A:  =E29*$E$34    // 应为 $E$21，但引用了错误的行`
`CapEx: =E29*$E$41   // 应为 $E$22，但行已偏移`

**发生原因：**
1. 先编写公式
2. 然后插入表头
3. 所有行引用发生偏移
4. 现在公式指向错误的单元格 → 出现 #REF! 错误

**正确做法：** 先锁定行布局，再编写公式

### 错误：跨情景的每个假设使用单行

**不要这样构建假设：**
```csv
Assumption,Bear,Base,Bull
Revenue Growth FY1,10%,13%,16%
Revenue Growth FY2,9%,12%,15%
```
这种垂直布局使得难以查看每个情景内跨年份的进展。

**错误原因：**
- 难以查看每个情景内跨年份的假设演变
- 难以在整个预测期内比较情景假设
- 审查情景逻辑时不够直观

**正确做法：**
- 为每个情景（Bear、Base、Bull）创建独立的区块
- 在每个区块内，水平显示跨预测年份的假设
- 这使得每个情景的假设作为一个连贯的集合更容易审查

### 错误：没有边框

**不要交付没有边框的模型：**
- 没有区域划分
- 所有单元格混在一起
- 难以阅读且不专业

**错误原因：**
- 未达到交付给客户的标准
- 难以导航
- 看起来业余

**正确做法：** 在所有主要区域周围添加边框

### 错误：错误的字体颜色或没有字体颜色区分

**不要这样做：**
- 所有文本都是黑色
- 只使用填充颜色（不改变字体颜色）
- 混淆哪些单元格是蓝色与黑色

**错误原因：**
- 无法区分输入值和公式
- 审计变得不可能
- 违反 xlsx 技能要求

**正确做法：** 所有硬编码输入使用蓝色文本，所有公式使用黑色文本，工作表链接使用绿色文本

### 错误：基于毛利润计算运营费用

**不要这样做：**
`S&M: =E33*0.15    // E33 = 毛利润（错误）`

**错误原因：**
- 运营费用与收入成比例，而非毛利润
- 产生不切实际的利润率进展
- 不符合企业的实际运营方式

**正确做法：**
`S&M: =E29*0.15    // E29 = 收入（正确）`

### 前五大错误总结

1.  **公式行引用错误** → 在编写公式**之前**定义所有行位置
2.  **缺少单元格批注** → 在创建单元格时**立即**添加批注，而不是在最后
3.  **简化的敏感性分析表** → 用完整的 DCF 重算公式填充所有单元格，而不是近似值
4.  **情景区块引用错误** → 确保 IF 公式从正确的 Bear/Base/Bull 区块中提取数据
5.  **没有边框** → 添加专业的区域边框，以达到交付给客户的外观标准

此外，请注意以下错误：

### WACC 计算错误
- 在资本结构中混合使用账面价值和市场价值
- 错误地使用股权贝塔而非资产/无杠杆贝塔
- 对债务成本应用错误的税率
- 使用错误的无风险利率（必须使用当前的 10 年期国债利率）
- 未能根据净债务与净现金头寸进行调整

### 增长假设缺陷
- 永续增长率 > WACC（产生无限价值）
- 预测增长率与历史表现不一致
- 忽略行业增长限制
- 收入增长与单位经济效益不匹配
- 没有运营理由的利润率扩张

### 终值错误
- 使用错误的增长方法（永续增长法 vs 退出倍数法）
- 终值 > 企业价值的 80%（表明过度依赖）
- 终值利润率与稳态假设不一致
- 终值的贴现期错误

### 现金流预测错误
- 运营费用基于毛利润而非收入
- D&A/CapEx 百分比与商业模式不匹配
- 营运资本变动计算不当
- 各年份间税率不一致
- NOPAT 计算错误

**这些是最常见的错误。在开始构建任何 DCF 模型之前，请重新阅读本节。**

## Excel 文件创建

**此技能使用 `xlsx` 技能进行所有电子表格操作。** xlsx 技能提供：
- 标准化的公式构建规则
- 数字格式约定
- 通过 `recalc.py` 脚本自动重新计算公式
- 全面的错误检查和验证

此技能创建的所有 Excel 文件必须遵循 xlsx 技能要求，包括零公式错误和正确的重新计算。

## 质量标准

每个 DCF 模型必须最大化以下方面：
1. 基于历史表现的**现实收入和利润率假设**
2. 采用适当 CAPM 方法的**合适的资本成本计算**
3. 显示估值范围的**全面的敏感性分析**
4. 有支持理由的**清晰的终值计算**
5. 支持情景分析的**专业的模型结构**
6. 所有关键假设的**透明文档记录**

## 输入要求

### 最低必需输入
1.  **公司标识符**：股票代码或公司名称
2.  **增长假设**：预测期的收入增长率（或"使用共识"）
3.  **可选参数**：
    - 预测期（默认：5 年）
    - 情景案例（Bear/Base/Bull 增长和利润率假设）
    - 永续增长率（默认：2.5-3.0%）
    - 如果不使用 CAPM，则提供特定的 WACC 输入

## Excel 模型结构

### 工作表架构

创建**两个工作表**：

1.  **DCF** - 主估值模型，底部带有敏感性分析
2.  **WACC** - 资本成本计算

**关键**：敏感性分析表放在 DCF 工作表的**底部**（不在单独的工作表上）。这可以将所有估值输出放在一起。

### 公式重新计算（强制）

创建或修改 Excel 模型后，**使用 `excel-author` 技能中的 `recalc.py` 脚本重新计算所有公式**：

```bash
python recalc.py [path_to_excel_file] [timeout_seconds]
```
示例：
```bash
python recalc.py AAPL_DCF_Model_2025-10-12.xlsx 30
```

脚本将：
- 使用 LibreOffice 重新计算所有工作表中的所有公式
- 扫描所有单元格中的 Excel 错误（#REF!、#DIV/0!、#VALUE!、#NAME?、#NULL!、#NUM!、#N/A）
- 返回包含错误位置和计数的详细 JSON

**预期输出格式：**
```json
{
  "status": "success",           // 或 "errors_found"
  "total_errors": 0,              // 错误总数
  "total_formulas": 42,           // 文件中的公式数量
  "error_summary": {}             // 仅在发现错误时存在
}
```

**如果发现错误**，输出将包含详细信息：
```json
{
  "status": "errors_found",
  "total_errors": 2,
  "total_formulas": 42,
  "error_summary": {
    "#REF!": {
      "count": 2,
      "locations": ["DCF!B25", "DCF!C25"]
    }
  }
}
```

**修复所有错误**，并在交付模型前重新运行 recalc.py，直到状态为 "success"。

### 格式标准

**重要**：遵循 xlsx 技能中关于公式构建规则和数字格式约定的规定。DCF 技能增加了特定的视觉呈现标准。

**配色方案 - 两层结构**：

**第一层：字体颜色（来自 xlsx 技能，必须遵守）**
- **蓝色文本（RGB: 0,0,255）**：所有硬编码输入（股价、股份数、历史数据、假设）
- **黑色文本（RGB: 0,0,0）**：所有公式和计算结果
- **绿色文本（RGB: 0,128,0）**：指向其他工作表的链接（WACC 工作表引用）

**第二层：填充颜色 — 专业蓝/灰色调色板（默认，除非用户另有指定）**
- **保持简洁** — 仅使用蓝色和灰色进行填充。不要引入绿色、黄色、橙色或多种强调色。颜色过多的模型显得业余。
- **默认填充调色板：**
  - **章节标题**：深蓝色背景（RGB: 31,78,121 / `#1F4E79`），白色加粗文本
  - **子标题/列标题**：浅蓝色背景（RGB: 217,225,242 / `#D9E1F2`），黑色加粗文本
  - **输入单元格**：浅灰色背景（RGB: 242,242,242 / `#F2F2F2`），蓝色字体 — 或者，如果追求极简，可以使用白色背景配蓝色字体
  - **计算单元格**：白色背景，黑色字体
  - **输出/汇总行**（每股价值、企业价值等）：中蓝色背景（RGB: 189,215,238 / `#BDD7EE`），黑色加粗字体
- **仅此而已 — 3 种蓝色 + 1 种灰色 + 白色。** 抵制添加更多颜色的冲动。
- 用户提供的模板或明确的颜色偏好**总是**覆盖这些默认设置。

**两层如何协同工作：**
- 输入单元格：蓝色字体 + 浅灰色填充 = "硬编码输入"
- 公式单元格：黑色字体 + 白色背景 = "计算值"
- 工作表链接：绿色字体 + 白色背景 = "来自其他工作表的引用"
- 关键输出：黑色加粗字体 + 中蓝色填充 = "这是答案"

**字体颜色告诉你它是什么（输入/公式/链接）。填充颜色告诉你你在哪里（标题/数据/输出）。**

### 边框标准（专业外观的必需项）

**粗边框**（1.5 磅）围绕主要章节：
- 关键输入章节
- 预测假设章节
- 5 年现金流预测章节
- 终值章节
- 估值汇总章节
- 每个敏感性分析表

**中等边框**（1 磅）用于子章节之间：
- 公司详情与历史业绩
- 增长假设与 EBIT 利润率与 FCF 参数

**细边框**（0.5 磅）围绕数据表：
- 情景假设表（熊市 | 基准 | 牛市 | 选定）
- 历史与预测财务数据矩阵

**无边框：** 表格内的单个单元格（保持干净、易于浏览）

**边框是必需的** — 没有专业边框的模型不适合交付给客户。

**数字格式**（遵循 xlsx 技能标准）：
- **年份**：格式化为文本字符串（例如，"2024" 而不是 "2,024"）
- **百分比**：`0.0%`（一位小数）
- **货币**：百万单位用 `$#,##0`；每股单位用 `$#,##0.00` — 标题中**必须**指定单位（"收入（$百万）"）

- **大数字**：`#,##0` 带千位分隔符
- **负数**：`(#,##0)` 用括号括起（**不要**用减号）

**单元格批注（所有硬编码输入的必需项）**：

根据 xlsx 技能，所有硬编码值都必须有单元格批注记录来源。格式："来源：[系统/文档]，[日期]，[参考]，[URL（如果适用）]"

**关键**：在**创建单元格时**添加批注。不要推迟到最后。

**关键 WACC 公式：**
```
市值 = 价格 × 股数
净负债 = 总债务 - 现金
企业价值 = 市值 + 净负债
股权权重 = 市值 / 企业价值
债务权重 = 净负债 / 企业价值
WACC = (股权成本 × 股权权重) + (税后债务成本 × 债务权重)
```

### 敏感性分析（DCF 工作表底部）

**术语提醒**："敏感性表格" = 简单的二维网格，包含行标题、列标题和每个数据单元格中的公式。**不是** Excel 的"数据表"功能（数据 → 假设分析 → 数据表）。你将使用 openpyxl 将常规 Excel 公式写入每个单元格。

**位置**：DCF 工作表的第 87 行及之后（**不是**单独的工作表）

**三个敏感性表格，垂直堆叠：**

1.  **WACC 与终值增长率**（第 87-100 行）- 5x5 网格 = 25 个带公式的单元格
2.  **收入增长率与息税前利润率**（第 102-115 行）- 5x5 网格 = 25 个带公式的单元格
3.  **贝塔值与无风险利率**（第 117-130 行）- 5x5 网格 = 25 个带公式的单元格

**需要编写的公式总数：75**（这是必需的，不是可选的）

**关键**：所有敏感性表格单元格必须使用 openpyxl 以编程方式填充公式。**不要**使用线性近似快捷方式。**不要**留下占位符文本或关于手动步骤的注释。**不要**以"太复杂"为由合理化留空单元格——使用 Python 循环来生成公式。

**表格设置：**
1.  创建带有行/列标题（要测试的假设值）的表格结构
2.  用公式填充**每个**数据单元格，该公式：
    - 使用行标题值（例如，WACC = 9.0%）
    - 使用列标题值（例如，终值增长率 = 3.0%）
    - 使用这些特定假设重新计算完整的 DCF
    - 返回该情景下的隐含每股价格
3.  交付时所有单元格必须包含有效的公式
4.  使用条件格式设置单元格格式：较高值用绿色渐变，较低值用红色渐变
5.  将基准情景单元格加粗
6.  表格之间留 1-2 个空行

**无需手动干预**——用户打开文件时，敏感性表格必须完全可用。

## 情景选择器实现

**三情景框架：**

### 悲观情景
- 保守的收入增长（历史范围低端）
- 利润率压缩或无扩张
- 更高的 WACC（风险溢价增加）
- 更低的终值增长率
- 更高的资本支出假设

### 基准情景
- 共识或管理层指导的收入增长
- 基于经营杠杆的适度利润率扩张
- 当前市场隐含的 WACC
- 与 GDP 一致的终值增长率（2.5-3.0%）
- 标准的资本支出假设

### 乐观情景
- 乐观的收入增长（预测范围高端）
- 显著的利润率扩张
- 更低的 WACC（风险溢价降低）
- 更高的终值增长率（3.5-5.0%）
- 降低的资本支出强度

**公式实现：**

**不要**在整个工作表中使用分散的嵌套 IF 公式。相反，创建一个使用 INDEX 或 OFFSET 公式从相应情景块中提取数据的汇总列。

**推荐模式（使用 INDEX）：**
`=INDEX(B10:D10, 1, $B$6)`，其中 `B10:D10` = 悲观/基准/乐观值，`1` = 行偏移量，`$B$6` = 情景选择器单元格（1、2 或 3）
**然后在所有预测中引用整合列**：
`第一年收入：=D29*(1+$E$10)`，其中 $E$10 是第一年增长的整合列值。

这种方法集中了情景逻辑，使模型更易于审计和维护。

## 常见变体

### 高增长科技公司
*   更长的预测期（7-10 年）
*   更高的初始增长率（20-30%）
*   随时间显著扩大的利润率
*   更高的 WACC（12-15%）
*   建模单位经济效益（用户数、ARPU 等）

### 成熟/稳定公司
*   较短的预测期（3-5 年）
*   适度的增长率（GDP +1-3%）
*   稳定的利润率
*   较低的 WACC（7-9%）
*   关注现金生成和资本配置

### 周期性公司
*   建模整个经济周期
*   在中周期标准化利润率
*   考虑低谷和高峰情景
*   根据周期性调整 Beta

### 多业务部门公司
*   为每个业务单元单独进行 DCF 估值
*   不同业务部门采用不同的增长率和利润率
*   分部加总估值
*   考虑协同效应

    *   如果 `status` 为 `"success"` → 继续步骤 4
    *   如果 `status` 为 `"errors_found"` → 检查 `error_summary` 并阅读 [TROUBLESHOOTING.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/finance/dcf-model/TROUBLESHOOTING.md) 获取调试指导
4.  **修复错误并重新运行 recalc.py**，直到状态为 "success"
5.  **抽查公式**：
    *   测试一个 FCF 公式 - 它是否引用了正确的假设行？
    *   更改情景选择器 - 整合列是否正确更新？
    *   验证收入公式引用了整合列（而非嵌套的 IF 公式）
6.  **交付模型**

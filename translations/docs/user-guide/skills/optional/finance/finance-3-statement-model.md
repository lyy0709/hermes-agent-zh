# 三张报表财务模型模板填充

完成并填充集成的财务模型模板，确保利润表、资产负债表和现金流量表之间的正确链接。

## ⚠️ 关键原则 — 填充任何模板前必读

**公式优先于硬编码（不可协商）：**
- 每个预测单元格、滚动项、链接和子合计必须是 Excel 公式 — 绝不能是预先计算好的值
- 使用 Python/openpyxl 时：写入公式字符串（`ws["D15"] = "=D14*(1+Assumptions!$B$5)"`），而非计算结果（`ws["D15"] = 12500`）
- 唯一应包含硬编码数字的单元格是：(1) 历史实际数据，(2) 假设页签中的驱动假设
- 如果您发现自己用 Python 计算一个值并将结果写入单元格 — 请停止。改为写入公式。
- 原因：当切换情景或假设改变时，模型必须能够灵活调整。硬编码会无声地破坏所有下游完整性检查。

**与用户逐步验证：**
1.  **映射模板后** → 向用户展示您已识别的页签/部分，并在触碰任何单元格前确认
2.  **填充历史数据后** → 向用户展示历史数据块，并确认数值/期间与源数据匹配
3.  **构建利润表预测后** → 运行子合计检查，向用户展示预测的利润表，在继续到资产负债表前确认
4.  **构建资产负债表后** → 向用户展示每个期间的平衡检查（资产 = 负债 + 权益），在继续到现金流量表前确认
5.  **构建现金流量表后** → 向用户展示现金勾稽（现金流量表期末现金 = 资产负债表现金），在最终确定前确认
6.  **不要从头到尾填充整个模型然后呈现完整版本** — 在每个报表处暂停，展示工作成果，及早发现错误

## 格式 — 专业蓝/灰配色方案（默认，除非模板/用户另有指定）

**保持颜色简洁。** 仅使用蓝色和灰色进行单元格填充。不要引入绿色、黄色、橙色或多种强调色 — 干净的模型需要克制。

| 元素 | 填充色 | 字体 |
|---|---|---|
| 部分标题（利润表 / 资产负债表 / 现金流量表标题） | 深蓝色 `#1F4E79` | 白色加粗 |
| 列标题（FY2024A, FY2025E 等） | 浅蓝色 `#D9E1F2` | 黑色加粗 |
| 输入单元格（历史数据、驱动假设） | 浅灰色 `#F2F2F2` 或白色 | 蓝色 `#0000FF` |
| 公式单元格 | 白色 | 黑色 |
| 跨页签链接 | 白色 | 绿色 `#008000` |
| 检查行 / 关键合计 | 中蓝色 `#BDD7EE` | 黑色加粗 |

**即 3 种蓝色 + 1 种灰色 + 白色。** 如果模板有自己的配色方案，则遵循模板。

字体颜色表示单元格*是什么*（输入/公式/链接）。填充色表示您*在哪里*（标题/数据/检查）。

## 模型结构

### 识别模板页签组织

模板的页签命名约定和组织方式各不相同。在填充之前，请查看所有页签以了解模板的结构。以下是常见的页签名称及其典型内容：

| 常见页签名称 | 要查找的内容 |
|------------------|----------------------|
| IS, P&L, Income Statement | 利润表 |
| BS, Balance Sheet | 资产负债表 |
| CF, CFS, Cash Flow | 现金流量表 |
| WC, Working Capital | 营运资本计划 |
| DA, D&A, Depreciation, PP&E | 折旧与摊销计划 |
| Debt, Debt Schedule | 债务计划 |
| NOL, Tax, DTA | 净经营亏损计划 |
| Assumptions, Inputs, Drivers | 驱动假设和输入 |
| Checks, Audit, Validation | 错误检查仪表板 |

**模板审查清单**
- 识别模板中存在哪些页签（并非所有模板都包含每个计划）
- 注意任何未列出的模板特定页签
- 理解页签间的依赖关系（例如，哪些计划数据会输入到主报表）
- 在每个页签上定位输入单元格与公式单元格

### 理解模板结构

在填充模板之前，请熟悉其现有布局，以确保数据输入到正确的位置，并且公式保持完整。

**识别行结构**
- 定位每个页签顶部的模型标题
- 识别部分标题及其视觉分隔
- 找到指示单位（百万美元、%、倍等）的单位行
- 注意区分实际数据与预测期间的列标题
- 确认期间标签（例如 FY2024A, FY2025E）
- 识别输入单元格与公式单元格（通常通过字体颜色区分）
**识别列结构**
- 确认最左侧列中的行项目标签
- 验证历史年份在预测年份之前
- 注意分隔历史期间与预测期间的视觉边框
- 检查所有工作表是否具有一致的列顺序

**使用命名区域**
模板通常对关键输入和输出使用命名区域。在输入数据之前：
- 查看模板中现有的命名区域（Excel 中的“公式”→“名称管理器”）
- 常见的命名区域包括：收入增长率、成本百分比、关键输出（净利润、EBITDA、总债务、现金）、情景选择器单元格
- 确保输入到这些命名区域所引用的单元格中

### 预测期间
- 模板通常从最后一个历史年份起向前预测 5 年
- 验证历史 (A) 列与预测 (E) 列是否清晰分隔
- 确认列使用财年表示法（例如，FY2024A、FY2025E）

## 利润率分析

**注意：仅当用户提示或模板明确要求时，才应执行以下利润率分析。如果未给出提示，请跳过此部分。**

在利润表 (IS) 工作表上计算并显示利润率，以跟踪运营效率并便于同业比较。

### 需包含的核心利润率

| 利润率 | 公式 | 衡量内容 |
|--------|---------|------------------|
| 毛利率 | 毛利润 / 收入 | 定价能力、生产效率 |
| EBITDA 利润率 | EBITDA / 收入 | 核心经营盈利能力 |
| EBIT 利润率 | EBIT / 收入 | 折旧摊销后的经营盈利能力 |
| 净利润率 | 净利润 / 收入 | 最终盈利能力 |

### 包含利润率的利润表布局

在每个利润行项目正下方显示利润率百分比：
- 毛利率 % 显示在毛利润下方
- EBIT 利润率 % 显示在 EBIT 下方
- EBITDA 利润率 % 显示在 EBITDA 下方
- 净利润率 % 显示在净利润下方

## 信用指标

**注意：仅当用户提示或模板明确要求时，才应执行以下信用分析。如果未给出提示，请跳过此部分。**

在资产负债表 (BS) 工作表上计算并显示信用/杠杆指标，以评估财务健康状况、债务能力和契约合规性。

### 需包含的核心信用指标

| 指标 | 公式 | 衡量内容 |
|--------|---------|------------------|
| 总债务 / EBITDA | 总债务 / 最近十二个月 EBITDA | 杠杆倍数 |
| 净债务 / EBITDA | (总债务 - 现金) / 最近十二个月 EBITDA | 扣除现金后的杠杆 |
| 利息保障倍数 | EBITDA / 利息费用 | 偿债能力 |
| 债务 / 总资本 | 总债务 / (总债务 + 权益) | 资本结构 |
| 债务 / 权益 | 总债务 / 总权益 | 财务杠杆 |
| 流动比率 | 流动资产 / 流动负债 | 短期流动性 |
| 速动比率 | (流动资产 - 存货) / 流动负债 | 即时流动性 |

### 信用指标层级检查

验证 Upside 情景显示最强的信用状况：
- 杠杆：Upside < Base < Downside（越低越好）
- 保障倍数：Upside > Base > Downside（越高越好）
- 流动性：Upside > Base > Downside（越高越好）

### 契约合规性跟踪

如果已知债务契约，则添加明确的合规性检查，将实际指标与契约阈值进行比较。

## 情景分析 (Base / Upside / Downside)

在 Assumptions 工作表中使用情景切换器（下拉列表）配合 CHOOSE 或 INDEX/MATCH 公式。

| 情景 | 描述 |
|----------|-------------|
| Base Case | 管理层指引或共识预期 |
| Upside Case | 高于指引的增长，利润率扩张 |
| Downside Case | 低于趋势的增长，利润率压缩 |

**需进行敏感性分析的关键驱动因素**：收入增长、毛利率、SG&A %、DSO/DIO/DPO、资本支出 %、利率、税率。

**情景审计检查**：切换器应能切换所有报表、所有情景下的资产负债表应平衡、现金应勾稽一致、层级关系应成立（对于净利润、EBITDA、自由现金流、利润率，Upside > Base > Downside）。

## 完成模型模板

本节提供完成任何三表财务模型模板的一般指南，同时保留现有公式并确保数据完整性。

### 步骤 1：分析模板结构

在输入任何数据之前，彻底审查模板以了解其架构：

**识别输入单元格与公式单元格**
- 寻找用于区分输入单元格和公式单元格的视觉提示（字体颜色、单元格底纹）
- 常见约定：蓝色字体 = 输入，黑色字体 = 公式，绿色字体 = 链接到其他工作表
- 使用 Excel 的“追踪引用单元格/从属单元格”（公式 → 追踪引用单元格）来理解单元格关系
- 检查可能控制关键输入的命名区域（公式 → 名称管理器）

**映射模板的流程**
- 识别哪些工作表的数据流向其他工作表（例如，Assumptions → IS → BS → CF）
- 注意任何辅助附表及其与主报表的链接
- 在填充数据之前，记录模板特定的行项目及其结构

### 步骤 2：在不破坏公式的情况下填充数据

**数据录入的黄金法则**

| 规则 | 描述 |
|------|-------------|
| 仅编辑输入单元格 | 除非有意替换公式，否则切勿覆盖包含公式的单元格 |
| 保留单元格引用 | 复制数据时，使用“粘贴值”(Ctrl+Shift+V) 以避免用源格式覆盖公式 |
| 匹配模板的单位 | 在输入数据之前，验证模板使用的是千、百万还是实际值 |
| 遵循符号约定 | 遵循模板现有的符号约定（例如，费用为正数还是负数） |
| 检查循环引用 | 如果模板使用迭代计算，请确保“启用迭代计算”已打开 |
**安全数据录入流程**
1. 识别指定用于输入的单元格（通常高亮显示或带有标签）
2. 首先录入历史数据，然后验证这些期间的公式计算是否正确
3. 录入用于预测计算的假设驱动因素
4. 检查计算输出，确认公式按预期工作
5. 如果必须修改公式单元格，请在更改前记录原始公式

**处理预建公式**
- 如果公式引用了尚未填充的单元格，在所有输入完成前，预计会出现临时错误（#REF!、#DIV/0!）
- 当公式产生意外结果时，追踪引用单元格以识别缺失或不正确的输入
- 切勿在未检查所有工作表标签中的公式依赖关系的情况下删除行/列

### 步骤 3：验证公式

**公式完整性检查**

在依赖模板输出之前，验证公式是否正常运行：

| 检查类型 | 方法 |
|------------|--------|
| 追踪引用单元格 | 选择公式单元格 → 公式 → 追踪引用单元格，以验证其引用了正确的输入 |
| 追踪从属单元格 | 验证关键输入是否流向预期的输出单元格 |
| 计算公式 | 使用公式 → 计算公式来逐步执行复杂计算 |
| 检查硬编码 | 预测公式应引用假设，不应包含硬编码值 |
| 使用已知值测试 | 输入简单的测试值以验证公式是否产生预期结果 |
| 跨工作表一致性 | 确保所有预测期间应用相同的公式逻辑 |

**需要注意的常见公式问题**
- 混合使用绝对/相对引用导致跨期间复制时结果不正确
- 指向外部文件或已删除区域的链接中断（#REF! 错误）
- 在收入增长前的早期期间出现除零错误（#DIV/0! 错误）
- 循环引用警告（对于利息计算可能是故意的）
- 预测列之间的公式不一致（使用 Ctrl+\ 查找差异）

**验证跨工作表链接**
- 确认出现在多个工作表上的值是链接的（不是重复的）
- 验证附表总计与主要报表上的相应行项目相符
- 检查所有工作表中的期间标签是否对齐

### 步骤 4：按工作表进行质量检查

填充模板后，对每个工作表执行以下验证检查：

**利润表质量检查**
- 历史期间的收入数据与源数据匹配
- 所有费用行项目合计等于报告的总计
- 小计（毛利润、息税前利润、税前利润、净利润）计算正确
- 税务计算逻辑适当（正确处理亏损）
- 预测驱动因素引用假设工作表（无硬编码）
- 期间环比变化方向合理

**资产负债表质量检查**
- 每个期间：资产 = 负债 + 权益（主要检查）
- 现金余额与现金流量表期末现金相符
- 营运资本账户与相关附表相符（如适用）
- 留存收益结转正确：期初留存收益 + 净利润 - 股息 +/- 调整 = 期末留存收益
- 债务余额与债务附表相符（如适用）
- 所有资产负债表项目符号适当（资产为正，大多数负债为正）

**现金流量表质量检查**
- 经营活动现金流顶部的净利润与利润表净利润相符
- 非现金加回项（折旧摊销、股权激励等）与其源附表/报表相符
- 营运资本变动符号正确（资产增加 = 现金使用 = 负值）
- 资本支出与不动产、厂房和设备附表或固定资产结转相符
- 融资活动与资产负债表中债务和权益账户的变动相符
- 期末现金与资产负债表现金相符
- 期初现金等于上一期间期末现金

**附表质量检查**
- 期初余额等于上一期间期末余额
- 结转逻辑完整（期初 + 增加 - 减少 = 期末）
- 附表总计与主要报表行项目相符
- 计算中使用的假设与假设工作表匹配

### 步骤 5：跨报表完整性检查

验证各个工作表后，确认三张报表已正确整合：

| 检查项 | 公式 | 预期结果 |
|-------|---------|-----------------|
| 资产负债表平衡 | 资产 - 负债 - 权益 | = 0 |
| 现金核对 | 现金流量表期末现金 - 资产负债表现金 | = 0 |
| 净利润链接 | 利润表净利润 - 现金流量表起始净利润 | = 0 |
| 留存收益 | 期初留存收益 + 净利润 - 股息 - 资产负债表期末留存收益 | = 0（根据需要调整股权激励/其他项目） |

### 步骤 6：最终审核

在认为模型完成之前：
- 切换所有情景（如适用）以验证每种情况下检查均通过
- 检查所有 #REF!、#DIV/0!、#VALUE! 和 #NAME? 错误，并解决或记录
- 确认所有输入单元格均已填充（搜索占位符值）
- 验证所有工作表中的单位一致
- 在进行任何额外修改前保存一个干净的版本

| 检查项 | 公式 | 预期结果 |
|-------|---------|-----------------|
| 资产负债表平衡 | 资产 - 负债 - 权益 | = 0 |
| 现金核对 | 现金流量表期末现金 - 资产负债表现金 | = 0 |
| 月度与年度现金 | 期末现金（月度） - 期末现金（年度） | = 0 |
| 净利润链接 | 利润表净利润 - 现金流量表起始净利润 | = 0 |
| 留存收益 | 期初留存收益 + 净利润 + 股权激励 - 股息 - 资产负债表期末留存收益 | = 0 |
| 股权融资 | Δ普通股/资本公积（资产负债表） - 股权发行（融资活动现金流） | = 0 |
| 第 0 年权益 | 募集权益（第 0 年） - 期初权益资本（第 1 年） | = 0 |

### 符号惯例参考

| 报表 | 项目 | 符号惯例 |
|-----------|------|-----------------|
| 经营活动现金流 | 折旧摊销、股权激励 | 正数（加回项） |
| 经营活动现金流 | Δ应收账款（增加） | 负数（现金使用） |
| 经营活动现金流 | Δ应付账款（增加） | 正数（现金来源） |
| 投资活动现金流 | 资本支出 | 负数 |
| 融资活动现金流 | 债务发行 | 正数 |
| 融资活动现金流 | 债务偿还 | 负数 |
| 融资活动现金流 | 股息 | 负数 |
### 循环引用处理

利息费用会产生循环引用：利息 → 净利润 → 现金 → 债务余额 → 利息

在 Excel 中启用迭代计算：文件 → 选项 → 公式 → 启用迭代计算。将最大迭代次数设置为 100，最大误差设置为 0.001。在"假设"选项卡中添加一个断路器开关。

### 检查类别

**第 1 部分：货币一致性**
- 在"假设"中识别并记录货币
- 所有选项卡使用一致的货币符号和单位
- 单位行与模型货币匹配

**第 2 部分：资产负债表完整性**
- 资产 = 负债 + 所有者权益（每个期间）
- 公式：资产 - 负债 - 所有者权益（必须 = 0）

**第 3 部分：现金流量表完整性**
- 现金与资产负债表关联（现金流量表期末现金 = 资产负债表现金）
- 月度与年度现金：期末现金（月度）= 期末现金（年度）
- 净利润与利润表关联（现金流量表净利润 = 利润表净利润）
- 折旧与摊销与附表关联
- 股权激励与利润表关联
- Δ应收账款、Δ存货、Δ应付账款与营运资本附表关联
- 资本性支出与折旧摊销附表关联

**第 4 部分：留存收益**
- 留存收益滚动检查：期初留存收益 + 净利润 + 股权激励 - 股息 = 期末留存收益
- 显示组件明细以便调试

**第 5 部分：营运资本**
- 应收账款、存货、应付账款与资产负债表关联
- 应收账款周转天数、存货周转天数、应付账款周转天数合理性检查（超出正常范围时标记）

**第 6 部分：债务计划表**
- 总债务与资产负债表关联（流动负债 + 长期债务）
- 利息计算与利润表关联

**第 6b 部分：股权融资**
- 股权发行收益与资产负债表普通股/资本公积增加关联
- 股权融资带来的现金增加 = 权益账户增加（必须平衡）
- 股权融资核对：Δ普通股/资本公积（资产负债表）= 股权发行（筹资活动现金流量）（必须 = 0）
- 第 0 年股权核对：股权融资（第 0 年）= 期初股权资本（第 1 年）

**第 6c 部分：净经营亏损计划表**
- 期初净经营亏损（第 1 年/成立时）= 0（新业务净经营亏损从零开始）
- 仅当税前利润 < 0 时净经营亏损增加（必须发生亏损才能产生净经营亏损）
- 递延所得税资产与资产负债表关联（净经营亏损计划表递延所得税资产 = 资产负债表递延所得税资产）
- 净经营亏损利用额 ≤ 80% 的税前利润（2017 年后联邦限制）
- 净经营亏损余额为非负数（不能利用超过可用额度）
- 仅当税前利润 < 0 时才产生净经营亏损
- 当应税收入 ≤ 0 时，所得税费用 = 0

**第 7 部分：情景层次结构**
- 绝对指标：上行 > 基准 > 下行（净利润、息税折旧摊销前利润、自由现金流）
- 利润率：上行 > 基准 > 下行（毛利率%、息税折旧摊销前利润率%、净利润率%）
- 信用指标：杠杆率上行 < 基准 < 下行（反向）

**第 8 部分：公式完整性**
- 销售成本、销售与营销费用、一般及管理费用、研发费用、股权激励由收入百分比驱动（无硬编码）
- 预测年份间公式一致
- 无 #REF!、#DIV/0!、#VALUE! 错误

**第 9 部分：信用指标阈值**
- 根据契约阈值将指标标记为绿色/黄色/红色
- 任何红色标记的摘要

### 主检查公式

将所有部分的状态汇总到一个主检查中：
- 如果所有部分通过 → "✓ 所有检查通过"
- 如果任何部分失败 → "✗ 检测到错误 - 请查看下方"

### 快速调试工作流

当主状态显示错误时：
1. 滚动查找红色高亮部分
2. 识别哪个检查类别失败
3. 导航到源选项卡进行调查
4. 修复根本问题
5. 返回"检查"选项卡验证解决情况
